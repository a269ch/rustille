# rustille-wasm

Turn pixels into Braille, in the browser or in Node.

```bash
npm install rustille-wasm
```

## Browser

The browser already decodes images, so hand Rustille the pixels:

```js
import init, { renderRgba } from "rustille-wasm";

await init();

const image = new Image();
image.src = "cat.png";
await image.decode();

const canvas = new OffscreenCanvas(image.width, image.height);
const context = canvas.getContext("2d");
context.drawImage(image, 0, 0);
const { data, width, height } = context.getImageData(0, 0, image.width, image.height);

console.log(renderRgba(data, width, height, { width: 80, dither: "floyd-steinberg" }));
```

## Encoded images

`renderBytes` decodes PNG, JPEG, WebP, BMP, GIF and TIFF inside WebAssembly:

```js
const bytes = new Uint8Array(await (await fetch("cat.png")).arrayBuffer());
console.log(renderBytes(bytes, { width: 80 }));
```

It is convenient but it is also most of the module's size. Build with
`--no-default-features` if you only ever pass pixels in.

## Drawing

```js
import init, { Canvas } from "rustille-wasm";

await init();

const canvas = new Canvas(100, 50);
canvas.circle(50, 25, 20);
console.log(canvas.render());
canvas.free();
```

TypeScript declarations are generated by `wasm-bindgen`, including the
`RenderOptions` interface.

See the [main README](https://github.com/a269ch/rustille) for the full
documentation.
